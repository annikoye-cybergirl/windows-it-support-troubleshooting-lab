# Windows IT Support Troubleshooting Lab

## Overview

This repository documents a hands-on Windows IT Support laboratory
designed to demonstrate practical troubleshooting, problem-solving,
documentation, and technical support skills.

The lab covers common IT Support scenarios involving:

- Network connectivity
- DNS troubleshooting
- Printer issues
- System performance
- Application troubleshooting
- User access and permissions

## Environment

- Operating System: Windows 11 Pro
- Virtualization: VirtualBox
- Device: Windows virtual machine
- Lab Device Name: WIN-ITLAB01

## Troubleshooting Methodology

Each incident follows a structured IT Support approach:

1. Identify the reported problem
2. Gather information
3. Investigate the symptoms
4. Identify the root cause
5. Apply a solution
6. Verify the solution
7. Document the incident
